# Code of Conduct

## Our Pledge

MechLang is built for researchers, educators, and students who believe
chemistry deserves better tooling. Everyone who contributes — regardless
of experience level, background, or discipline — deserves a respectful
and constructive environment.

## Our Standards

**We encourage:**
- Clear, constructive feedback on code and ideas
- Welcoming questions from beginners
- Crediting prior work and inspirations
- Focusing on what's best for the project and its users

**We do not tolerate:**
- Dismissive or condescending language
- Personal attacks or harassment of any kind
- Gatekeeping based on experience level

## Scope

This code of conduct applies to all MechLang spaces — GitHub issues,
pull requests, discussions, and any other project communication.

## Enforcement

Violations can be reported to the maintainer at the email listed on the
GitHub profile. All reports will be handled confidentially.

---

*MechLang is a small, focused project. Let's keep it that way —
clean code, clean conversations.*
