# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| v0.9.x and above | ✅ |
| Below v0.9 | ❌ |

## Reporting a Vulnerability

MechLang is a CLI-based DSL tool with no network surface or authentication layer.
However, if you discover a security vulnerability (e.g. malicious .mech file
parsing, unsafe file output handling), please report it **privately**.

**Do not open a public GitHub issue for security vulnerabilities.**

### How to Report

Use GitHub's private vulnerability reporting:
1. Go to the [Security tab](https://github.com/Forzals-Fav9/mechlang/security)
2. Click **"Report a vulnerability"**
3. Describe the issue with steps to reproduce

### What to Expect

- Acknowledgement within **72 hours**
- Resolution or mitigation plan within **2 weeks**
- Credit in the changelog upon fix (if desired)
